# Meerkat Fugue documentation

Fugue connects GitHub or GitHub Enterprise repositories to built-in tickets,
Linear or Jira. Each repository has its own persistent specialist team and issue
queue, with review and delivery evidence visible in one operator application.

## Start here

- [Your first repository](./getting-started.mdx): install, connect access, prepare

- [How Fugue works](./overview.mdx): the repository, team, tracker and runtime model.
- [Daily work](./daily-work.mdx): Home, Board, Agents, review and connection recovery.
